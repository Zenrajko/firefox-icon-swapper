3. Apply selected icon to bookmark

  1. Type about:profiles in the address bar to open the Profiles page.
  2. Click the "Open Folder" button in the "Root Directory" row of the current profile.
  3. Open the "chrome" folder.
  4. Open "userChrome.css" in a text editor (create the file first if it doesn't exist yet).

  5. Click the button below to generate the CSS for the icon and copy it to the clipboard.

  6. Paste the text in the clipboard into the userChrome.css file, and save the file.
  1. Restart Firefox so the custom icons take effect.

One-time setup: enable toolkit.legacyUserProfileCustomizations.stylesheets in about:config if not already enabled — see the README for details.
